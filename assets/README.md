# 이미지와 화면 캡처

`assets/screenshots/*.jpg`는 2026-10-05 공개 React 소스를 로컬에서 직접 조작해 촬영한 화면입니다. 캡처에는 실제 사용자·매장·추천 기록 대신 가상 데이터가 표시됩니다.

| 파일 | 화면 |
| --- | --- |
| `home.jpg` | 가상 매장 큐레이션과 취향 선택 진입 |
| `tray.jpg` | 두 빵을 담고 세 번째 빵의 취향을 고르는 과정 |
| `bags.jpg` | 추천 봉투 개봉 전 |
| `result.jpg` | 봉투 개봉 후 가상 매장의 특징 |
| `review.jpg` | 가상 매장 리뷰 입력 |

수집한 매장 사진, 홈페이지·관광정보의 재사용 미확인 사진, 이미지 크레딧 원본 데이터는 공개하지 않습니다. 프론트엔드의 빵·트레이·봉투 연출 에셋과 매장 일러스트는 프로젝트 UI용 자료이며 실제 판매 상품의 사진이 아닙니다. 에셋의 재배포 권한은 [이용 안내](../LICENSE)를 따릅니다.
