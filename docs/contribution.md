## 기획과 최종 구현의 관계

초기 논의에서 검토한 Spark 전처리 위치, MongoDB 외 저장소, LLM 후보가 모두 최종 구현에 채택된 것은 아닙니다. 현재 공개 소스는 Python 수집·정제, MongoDB 원문 저장, LLM 태그 분류, Spark 점수 집계로 이어지며 온라인 API는 저장된 점수를 조회합니다.

점수 설명은 공개 코드에서 확인한 외부 `m=5`, 내부 `m=3`, 반감기 180일, `α=n/(n+10)`을 기준으로 합니다. 저장된 정수 건수만으로 과거 점수를 완전히 재현할 수 있다는 설명은 사용하지 않습니다. 당시 입력과 기준일 또는 가중합이 추가로 필요합니다.

## 팀 구현과 개인 역할

링크한 코드는 검토한 설계와 현재 구현을 함께 읽기 위한 팀 산출물입니다. 프론트엔드, 추천 API, LLM 분류기, Spark 집계 파일 전체를 박민규가 단독 구현했다는 의미는 아닙니다. 팀원의 코드·설계·에셋 기여는 각 작성자에게 귀속됩니다.

공개본의 합성 미리보기, 화면 캡처, 테스트·빌드 결과는 [검증 기록](verification.md)에서 별도로 확인할 수 있습니다. 기획안 검토나 발표 자료 구성 자체를 추천 품질 향상·운영 성과의 증거로 제시하지 않습니다.
