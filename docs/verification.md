# 공개본 검증 기록

검증일: 2026-10-05 · 환경: Windows, Node.js 24.18.0, pnpm 11.19.0.

| 검사 | 결과 | 범위 |
| --- | --- | --- |
| `pnpm install --frozen-lockfile` | 설치 확인 | 잠금 파일 기준 의존성 |
| `pnpm test` | 124 passed / 0 failed | UI 상태·API 계약·세션 경계·합성 미리보기 계약 |
| `pnpm build` | 성공 | React 프로덕션 번들 |
| 브라우저 미리보기 | 확인 | 홈 → 빵 3종 담기 → 가상 로그인 → 추천 → 봉투 개봉 → 리뷰 입력 |
| 소스 공개 점검 | 별도 검사 수행 | 비밀값 패턴·운영 주소·제외 대상 파일·문서 링크 |

원본 프론트엔드 테스트 123개에서 로컬 API 기본값과 명시적 Google 설정 정책에 맞춰 설정 검사를 수정했습니다. 합성 API 응답이 실제 어댑터에 맞는지 확인하는 테스트 1개를 추가했습니다.

## 캡처 조건

`pnpm demo`로 같은 React 컴포넌트·스타일·상태 전이를 실행했습니다. 별도 목업 이미지나 정적 화면 재구현이 아닙니다. 다만 계정·가게·집계 데이터는 합성이며 추천 결과도 고정 응답입니다. 화면 상단에 그 사실을 표시했습니다. 매장 사진은 프로젝트의 일러스트로 대체했습니다.

## 이번에 검증하지 않은 것

- 실제 Google 로그인, 운영 인증·권한·데이터 저장
- Spring API 통합 실행과 운영 DB 스키마 마이그레이션
- 수집 사이트 연결, LLM 추론 정확도, Spark 점수 재계산
- 추천 품질·매장 방문·리뷰 전환 지표
- 다중 물리 서버 성능과 장애 복구

프론트엔드 테스트 통과를 백엔드 비즈니스 로직 검증이나 제품 전체의 운영 안전성 검증으로 해석하지 않습니다.
